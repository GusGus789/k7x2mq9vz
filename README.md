# zcode-plugin-icons

自建 ZCode 插件使用的图标资源（512×512 PNG）。

ZCode 客户端只渲染以 `https://` 开头的图标地址，因此这些图标通过 GitHub Raw 提供给
`marketplace.json` 的 `icon` 字段使用。
